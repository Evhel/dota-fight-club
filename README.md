# Dota 2 Clan Stats

Создай сайт-приложение, который выводит статистику по матчам в Дота 2.

Называется «Бойцовский клуб Dota 2».
Мы играем с друзьями в Dota 2 в закрытых лобби с паролем 5х5.
Это не постоянный набор человек, иногда к нам кто-то присоединяется новый, иногда кто-то не играет. Всего нас больше 30-ти человек и число возможно увеличится до 40.
Приложение должно собирать статистику из игр и выдавать метрики этих статистик.



У нас есть файлы JSON со статистикой для каждой игры, я прикладываю как вложение пример такого файла.

 

Сделай оформление в дарк фэнтези темно-зеленом стиле и используй в оформлении картинку, которую я приложу. Не используй в оформлении желтые или рыжие цвета.

 

Должно быть два варианта входа на сайт – как админ и как игрок. По умолчанию все входят как игрок, но есть возможность выйти и зайти как администратор – по паролю «14888». У администратора есть возможность загружать новые игры или удалять уже загруженные.

 

Должна быть скрытая база игроков – за каждым по его стим айди присваивается первый ник, под которым он заходил. В дальнейшем статистика для каждого игрока подсчитывается по его стим айди, но в приложении статистика отображается по его первому нику.

 

Все значения данных пиши в целых числах (100). Винрейт пиши в целых числах в процентах (100%).

 

 


Страница 1 (Для администратора)
Должна быть страница для импорта файлов JSON с метриками из матчей. Кнопка «добавить матч» и поле для импорта файлов. Также должна быть возможность пакетного импорта сразу нескольких файлов. При импорте нового матча, если такой матч уже был введен ранее – выводится уведомление, что матч уже учтен (если использовался пакетный импорт матчей и некоторые матчи уже были учтены ранее – остальные матчи учитываются).

 

 

Страница 2 (Главная страница)

 

Сверху календарь активности игр

Снизу общая статистика за все игры

Слева общая статистика за все время:

1.      Общее количество игр

2.      Суммарное количество времени, затраченное на игры и пик

3.      Общее количество игроков за все время

4.      Количество побед за тьму и за свет

5.      Количество игр в каждом режиме

Справа рекорды (при нажатии на рекорд перекидывает на страницу игры или игрока):

1.      Длительность самой короткой игры

2.      Длительность самой длинной игры

3.      Самое большое количество Observer wards placed за игру

4.      Самое большое количество Sentries wards placed за игру

5.      Самое большое количество Wards destroyed за игру

6.      Самое популярное слово в общем чате

7.      Имя игрока, который больше всех сыграл игр и количество игр

8.      Имя игрока с самым большим винрейтом за все время

9.      Имя игрока, который чаще всех использует фразы для общего чата

10.  Имя игрока, который чаще всех «дает пять» за все время

Снизу страницы облако слов в чате за все время (слова, которые чаще упоминаются, больше в размере)

 

 

 

 

Страница 3


На этой странице должна быть таблица-список всех учитываемых матчей. Для каждого матча должны быть написаны:
1. Порядковый номер матча (по дате и времени)
2. Дата и время начала матча

3. Режим матча
4. Продолжительность матча

5. Продолжительность стадии пиков
6. Кто победил – Тьма или Свет
5. Количество смертей за свет и за тьму
Все матчи сортируются по дате и времени начала матча. 
У администратора есть возможность удалить каждый матч 



Можно кликнуть на каждый матч и перейти на его страницу на странице 4



Страница 4

Поиск матча по номеру

На этой странице сверху есть поле для ввода порядкового номера игры и кнопка «найти игру».

 

После ввода номера игры должна открываться статистика конкретно этой игры:

Два списка игроков для света и тьмы, имя героя для каждого игрока, количество Убийств, смертей и помощи (KDA) для каждого игрока, Общая ценность в золоте для каждого игрока. Должно быть написано, кто победил – свет или тьма.

 


Страница 5

Игроки

Тут должен быть общий список всех игроков в табличном виде. Сортировка списка по количеству сыгранных игр от бОльшего к меньшему.

Для каждого игрока должно быть написано:

Ник

Количество сыгранных игр

Общий винрейт (количество выигрышей / количество поражений)

Общее количество времени, проведенное в играх (игры+стадия пика)

Количество уникальных героев за все время

Число максимальной серии побед

Число максимальной серии поражений

Число и вид текущей серии (поражения или победы)

Самое часто используемое слово в общем чате

Имя игрока, совместно с которым процент выигрыша выше всего

Имя игрока, совместно с которым процент выигрыша ниже всего

 

Страница 6

Герои

Тут должен быть общий список всех героев Dota 2 в табличном виде.

Должна быть возможность менять сортировку – а) по алфавиту б) по винрейту в) по количеству сыгранных игр.

Для каждого героя должны быть написаны:

Имя героя

Количество сыгранных игр

Винрейт героя

Количество игр, в которых забанили этого героя

Количество игр, в которых этого героя забанили первым

Страница 7

Игрок

Тут должен быть выпадающий список с ником игрока и кнопка «найти игрока»

По нику выводится информация об игроке:

Ник

Количество сыгранных игр

Винрейт

Общее количество времени, проведенное в играх и на стадии пика

Количество уникальных героев за все время

Список уникальных героев за все время

Число максимальной серии побед

Число максимальной серии поражений

Число и вид текущей серии (поражения или победы)

Самый большой KDA в игре

Средний KDA в игре

Самая большая ценность в золоте (кликабельное и переводит на страницу этого матча на странице 4)

Средняя ценность в золоте

Самое большое количество убитых крипов за игру (кликабельное и переводит на страницу этого матча на странице 4)

Среднее количество убитых крипов за игру

Герой, на котором сыграно больше всего игр

Герой, на котором самый большой винрейт

Самое часто используемое слово в общем чате

Максимальное количество Observer wards placed за игру (кликабельное и переводит на страницу этого матча на странице 4)

Максимальное количество Sentries wards placed за игру (кликабельное и переводит на страницу этого матча на странице 4)

Максимальное количество Wards destroyed за игру (кликабельное и переводит на страницу этого матча на странице 4)

Имя игрока, совместно с которым процент выигрыша выше всего (кликабельное и переводит на страницу этого игрока на странице 7)

Имя игрока, совместно с которым процент выигрыша ниже всего (кликабельное и переводит на страницу этого игрока на странице 7)

Страница 8

Рекорды

На этой странице выводятся рекорды за все игры. Вместе с рекордом выводится ник, если это относится к конкретному игроку (при клике на ник открывается страничка игрока на странице 7):



1. Количество убийств

2. Количество смертей

3. Количество помощи

4. KDA с 0 смертей

5. Ценность в золоте

6. Ласт хиты

 

 

Страница 9

Игрок vs Игрок

Тут должен быть выпадающий список с ником игрока, для которого будут выводиться пары, и кнопка «найти игрока».

После ввода ника игрока в табличном виде выводятся ники всех остальных игроков. Сортировка по количеству совместных игр.

Для каждого игрока выводятся:

Ник (кликабельный и переводит на страничку этого игрока на странице 7)

Общее количество совместных игр

Количество игр, сыгранных в одной команде

Винрейт для игр, сыгранных в одной команде

Количество игр, сыгранных в разных командах

Винрейт для игр, сыгранных в разных командах
