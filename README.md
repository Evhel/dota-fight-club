Проект для меня и моих друзей со статистикой игр в лобби. Создан в Lovable.

Матчи хранятся в `src/data/matches`. Для добавления новых записей используйте отдельный [парсер клуба](https://github.com/Evhel/dota-fight-club-parser): он читает папку Dota, проверяет результат и делает коммит одной кнопкой.

Даты и итоговые показатели 149 из 153 исторических игр восстановлены из серверной сводки в демках. Четыре игры без найденных записей сохранены как старые данные; их урон и лечение не участвуют в рекордах. Steam ID хранятся строками, чтобы JavaScript не округлял их.

Проверка данных: `bun run check:data`. Основная сборка Lovable: `bun run build`. Дополнительная статическая сборка GitHub Pages: `bun run build:pages`. Зеркало обновляется workflow `.github/workflows/pages.yml` после отправки в main.

Локальная проверка регрессии рекордов: `node --experimental-strip-types --test scripts/stats.test.mjs` (Node 22.18+).
