КАК ДОБАВЛЯТЬ ДАННЫЕ (без базы данных)

1) МАТЧИ
   Положи JSON-файл матча в папку:  src/data/matches/
   Имя файла — любое, удобнее всего <match_id>.json
   Ничего больше делать не нужно: при сборке сайта файлы подхватываются автоматически.
   Дубликаты по match_id отбрасываются.

2) АВАТАРКИ
   Картинку положи в папку:  public/avatars/
   Строку добавь в файл:     public/avatars/avatars.txt
   Формат строки:            steam_id = имя_файла
   Пример:                   76561198262536560 = vasya.jpg

3) НАГРАДЫ
   Картинку положи в папку:  public/awards/
   Строку добавь в файл:     public/awards/awards.txt
   Формат строки:            steam_id | имя_файла | Название награды
   Пример:                   76561198025641140 | most-games.png | Больше всех сыграл в сезоне

После изменений — коммит и пуш в GitHub, сайт пересоберётся.

--------------

Заходим в powershell в папке проекта
git pull              - скачать изменения с гитхаба на комп

закидываем матчи в папку

git add src/data/matches/
git commit -m "Обновила матчи"
git push
